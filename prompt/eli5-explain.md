# Prompt A: explain simply (ELI5)

Replace `[TOPIC]`, then paste into a fresh agent session.

```
Explain [TOPIC] to a complete beginner, like I'm 5.
- Max 150 words (not counting the questions). Short sentences. No jargon; if a term is unavoidable, define it in 5 words.
- Start with one everyday analogy (kitchen, post office, etc.), then one sentence on where the analogy breaks.
- Then one concrete example with real values.
- End with: "The one thing to remember: ..." (one sentence).
- Then ask me 2 questions to check I understood, and wait. Don't answer them yourself.
  When I reply, correct each answer in 1–2 sentences.
```
